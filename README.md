# Mana and Malice


### About
Mana and Malice is a single-player story-driven game that challenges the norm for player agency in narrative games. It takes place in the 1950s in a fictional world where Magic exists! You play as an interrogator who's goal is to choose who is guilty out of 3 suspects. 

The main catch is that the suspect is actually an AI agent who is making thoughtful decisions based on the interrogators every move! There is currently only 1 episode out, more to come later...

Tech Stack:

- **Pydantic** for data validation and dependency creation.
- **Pydantic AI** for Agent Creation
- **Open AI** for embeddings and agent model
- **Postgresql** for the database
- **Fast API** for the server creation
- **Godot** for the game engine
